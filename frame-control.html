Space Explorers 360

Native Steam Frame player (Linux ARM64). Click Install, then in the Frame Control confirm dialog enter the entry Name Space Explorers 360 and pick launch.sh as the program to run.

Install with Frame Control

If nothing opens, install Frame Control and pair it with your headset, then come back and click Install again.

Manual install: download se360-vr-linux-arm64.zip and drop it onto Frame Control.
