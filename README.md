# se360-install

Public install files for **Space Explorers 360** (native Steam Frame player).

- [Install with FrameDrop](https://framedropvr.com/install?manifest=https%3A%2F%2Ffivedegreesvr.github.io%2Fse360-install%2Fse360-vr.framedrop.json)
- `se360-vr-linux-arm64.zip`: ARM64 build for drag-and-drop into FrameDrop.
- `se360-vr.framedrop.json`: `framedrop.install/v1` manifest.
